# AEDCODE

Completo compendio de trabajos mandados desde la asegnatura de Algorítmica y Estructura de Datos (de ahora en adelante AED).

## Getting Started

This is a java course, so everything is programmed in java (java17 should suffice). Further, this repository is structured like a Maven project. You will find that the test files they require, as well as the library provided for the class, must be imported in a roundabout way, I use maven to manage library thusly.

### Prerequisites

The things you need before installing the software.

* Java (circa 17 should be alright)
* Java Maven
* Any code editor I guess lol (I use astro-nvim(modded) and vscode)

### Installation

A step by step guide that will tell you how to get the development environment up and running.

